# MotionBlocks

**MotionBlocks** — проект по сбору и анализу данных о движении человека с помощью носимого устройства.

Устройство записывает движения, Python-инструменты сохраняют данные, модели машинного обучения учатся их распознавать. Конечная цель — **детектировать падение и отправить оповещение доверенному лицу**.

Проект делается вместе с детьми: они участвуют в записи данных, тестировании и придумывании идей.

---

## Как это работает

```text
M5StickC Plus2          носимое устройство с акселерометром и гироскопом
    ↓ Wi-Fi (100 Гц)
http_logger.py          принимает данные, сохраняет в CSV
    ↓
motion_browser.py       просмотр и разметка записей
compute_features.py     извлечение признаков из сырых данных
    ↓
Orange / scikit-learn   обучение модели классификации движений
    ↓
Guardian (в разработке) детекция падения → оповещение
```

---

## Текущее состояние

Что работает сейчас:

- Устройство записывает IMU данные (акселерометр + гироскоп) на частоте **100 Гц**
- Передача по Wi-Fi через HTTP без потерь (FreeRTOS двухъядерная архитектура)
- Управление записью кнопками на устройстве
- Отображение статуса батареи, сессии и записи на экране устройства
- Сохранение данных в CSV с метаданными
- Просмотр и разметка записей через `motion_browser.py`
- Первый ML эксперимент в Orange Data Mining — 99.5% на обучающих данных

В разработке:

- Расширение датасета
- FFT признаки
- scikit-learn baseline
- Guardian PoC — детекция падения + оповещение

## Структура репозитория

```text
firmware/
    m5stickc-plus2/         прошивка устройства
tools/
    http_logger.py          приём данных по Wi-Fi
    motion_browser.py       просмотр и разметка записей
    compute_features.py     извлечение признаков
    analyze_recordings.py   анализ качества записей
docs/
    onboarding/             документация для новых участников
    guides/                 руководства пользователя
data/                       локальные данные (не в Git)
    raw/                    сырые CSV файлы
    metadata/               метаданные экспериментов
    analysis/               результаты анализа
```

## Принципы проекта

- Устройство остаётся простым — вся логика на стороне Python и анализа
- Сырые данные читаемы — CSV и JSON, никаких бинарных форматов
