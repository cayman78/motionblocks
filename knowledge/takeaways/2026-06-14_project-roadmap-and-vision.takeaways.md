## Текущий проект — M5StickC Plus2

### Фаза 1 — Датасет и ML

```
1. Расширенный датасет
   — несколько субъектов (минимум 2-3)
   — классы: idle, walking, running, jumping,
     squats, stairs_up/down, shake, fall-like
   — 10+ записей на класс на субъекта

2. FFT фичи в compute_features.py
   — частотные характеристики для ритмических движений
   — улучшит разделение walking / running / jumping

3. scikit-learn baseline
   — воспроизводимая модель в коде
   — сравнение алгоритмов: kNN, Random Forest, SVM
   — сохранение модели (.pkl) для последующего использования
```

### Фаза 2 — firmware_2_classifier

```
4. Edge Impulse
   — обучить модель и задеплоить на устройство
   — real-time классификация движений на экране
   — "сейчас: ходьба / прыжки / покой"
```

### Фаза 3 — Guardian PoC

```
5. firmware_3_guardian
   — тревожная кнопка (ручное срабатывание)
   — автосрабатывание при аномальных движениях
   — настраиваемый порог
   — анализ ошибок первого и второго рода с детьми
   — выбор оптимального порога специфичности
   — образовательная ценность: статистика через реальный прибор
```

### Фаза 4 — Конкурс и публикация

```
6. Оформление результатов
   — научная постановка задачи
   — методология сбора данных и обучения
   — результаты, выводы, ограничения
   — участие в школьных / региональных конкурсах
```

Сильные стороны для конкурсного позиционирования:
- полный end-to-end pipeline собственной разработки
- аппаратура + сбор данных + ML — не "взяли готовый датасет"
- демонстрация ошибок 1/2 рода через реальный прибор
- применение к задаче безопасности пожилых людей

## Следующий проект — суточный мониторинг

### Постановка задачи

Не детектор движений — а детектор отклонений от персонального
ритма жизни. Аналогия: антифрод система — не знает что такое
мошенничество в абсолюте, знает что такое норма конкретного
клиента и реагирует на отклонение.

Примеры отклонений:
- не вовремя встал
- ходит медленнее обычного
- не было паттерна похожего на завтрак
- нетипичная активность ночью

### Архитектура

```
7. Персональный baseline
   — профиль нормального суточного поведения
   — учёт времени суток, дня недели
   — индивидуальная норма у каждого субъекта

8. Детектор отклонений
   — "сегодня не так как обычно"
   — score опасности / аномальности

9. Интерпретация через LLM агент
   — на основе идентифицированных паттернов
   — формулировка возможных рисков
   — рекомендации / тревога

10. Мониторинг и дашборд (MotionLink концепция)
    — семейный / медицинский
    — история паттернов
```

## Железо — текущее и следующее

### M5StickC Plus2 — ограничения

- Батарея 200 мАч: ~30 минут при Wi-Fi + IMU + дисплей
- Греется при активном Wi-Fi (ESP32 ~150-200 мА)
- Не пригоден для суточного мониторинга в текущей конфигурации

### M5StickC Plus2 — варианты продления автономности

```
Вариант A: доп аккумулятор на ремешке через USB-C
  — 1000-2000 мАч, работает часами
  — никаких изменений в прошивке
  — подходит для Guardian PoC и демонстрации

Вариант B: SD карта для автономной записи
  — отключить Wi-Fi во время записи
  — данные на карту, синхронизация по расписанию
  — потребление падает в 3-4 раза
  — нужна отдельная прошивка "автономный логгер"

Вариант C: комбинация A + B
  — доп аккумулятор + SD карта
  — Wi-Fi только для синхронизации раз в час
  — реальная схема для длительного мониторинга
```

### Следующее железо — Android

Для суточного профилирования правильный выбор — Android
смартфон или Samsung Watch:
- носится весь день, батарея решена
- IMU, HR и другие сенсоры есть
- большой выбор устройств и ценовых категорий
- SDK доступен (Kotlin + Wear OS + Health Services API)
- сложность программирования выше, но с AI ассистентами
  технологический гэп закрывается

Отклонённые альтернативы:
- Готовый фитнес-трекер: закрытый API, нет гибкости
- XIAO nRF52840: хорош для конечного продукта / промышленного
  устройства, но требует разработки с нуля; рассмотреть
  если появится конкретная необходимость своего устройства
- Android Watch б/у (~$50-80): реалистичный вариант для
  следующего этапа

### Решение по железу

Текущее: M5StickC Plus2 достаточен для всех PoC фаз 1-4.
Следующее: Android / Samsung Watch для суточного мониторинга.
Выбор следующего железа — после завершения Guardian PoC,
когда понятно что именно нужно от следующего устройства.

## Применение — медицинский мониторинг

### Постановка задачи

Непрерывный автоматический мониторинг пациента как альтернатива
ручному NEWS2 (National Early Warning Score).

Сейчас в больницах: медсестра раз в несколько часов вручную
меряет пульс, давление, температуру, считает балл вручную.
Работает, но с задержкой в часы.

Цель: непрерывный персональный EWS (Early Warning System)
который детектирует предкритические состояния за часы до
клинического ухудшения.

### Применения

```
Стационар без реанимации
  — пациент под наблюдением, но без постоянных датчиков
  — простое носимое устройство на запястье

Домашнее наблюдение
  — выписан, но требует мониторинга
  — хронические заболевания
  — постоперационный период

Пожилые люди дома
  — пересечение с Guardian концепцией
  — суточный ритм + витальные показатели
```

### Сенсорный набор

```
IMU (уже есть)
  → двигательная активность
  → паттерны движения
  → беспокойство / ажитация
  → падения

MAX30102 (~$3, I2C, Grove)
  → пульс (ЧСС)
  → вариабельность пульса (HRV)
  → SpO2 (насыщение кислородом)

MLX90614 (~$5, I2C)
  → бесконтактная температура кожи

Акселерометр → частота дыхания
  → через движение грудной клетки
  → уже есть в IMU, нужен алгоритм
```

Всё подключается к ESP32 / XIAO через I2C.
Аппаратная часть решаема без больших бюджетов.

### Алгоритмическая часть

```
Персональный baseline витальных показателей
  → норма ЧСС, SpO2, температуры, активности
  → учёт времени суток

Непрерывный score опасности
  → комбинация отклонений по всем каналам
  → аналог NEWS2 но в реальном времени

Предиктивная модель
  → предкритическое состояние за часы до ухудшения
  → LLM интерпретация паттернов
```

### Связь с текущим проектом

Движение уже есть. MAX30102 подключается к M5StickC
через Grove порт — один провод, одна библиотека.
Это следующий логичный сенсор для расширения системы.

Концептуальная преемственность:
```
Guardian PoC (движение)
  → суточный профиль (движение + ритм)
  → медицинский EWS (движение + витальные показатели)
```

### Позиционирование

Серьёзная научная постановка с реальным медицинским применением.
Большой рынок. Актуальная задача.

Для детского проекта — формулировка "носимый помощник для
наблюдения за здоровьем" понятна и вдохновляет.

### Путь к собственному устройству

Существующие носимые устройства для мониторинга здоровья
проектируются для молодых технически грамотных людей.
Для пожилых они непригодны — мелкий экран, сложный интерфейс,
требуют синхронизации со смартфоном.

**Требования к устройству для пожилых (accessibility design):**

```
Физическое:
  — одна большая кнопка SOS
    (нажимается даже дрожащей рукой)
  — крупный дисплей, высокий контраст
  — простой ремешок, ничего не надо настраивать
  — автономность минимум сутки
  — водозащита
  — лёгкий и небольшой

Интерфейс:
  — одна кнопка = одно действие
  — или полностью автоматический режим
    без взаимодействия со стороны пользователя

Для персонала / семьи:
  — дашборд в браузере
  — простые понятные оповещения
  — история показателей
```

**Производство малой серии — JLCPCB:**

JLCPCB — китайский производитель печатных плат (PCB)
и сборки устройств (PCBA). Один из стандартных инструментов
hardware стартапов.

```
PCB:  от $2 за 5 штук, производство 24-48 часов
PCBA: присылаешь схему и список компонентов →
      они покупают и паяют → получаешь готовое устройство
      100 плат: $500-2000 в зависимости от сложности
3D печать корпусов: тоже доступна
```

Раньше малая серия электроники стоила десятки тысяч долларов.
Сейчас через JLCPCB это доступно небольшой команде.

**Путь к продукту:**

```
1. PoC на M5StickC Plus2
   — доказываем концепцию (сейчас)

2. Прототип на XIAO nRF52840 + кастомная плата
   — разрабатывает студент или небольшая команда
   — стоимость разработки $5-15k

3. Малая серия 50-100 штук через JLCPCB
   — стоимость одного устройства $20-50 при партии 100

4. Клиническое исследование
   — партнёрство с больницей

5. Грант / инвестиции на масштабирование
```

**Грантовые программы:**

```
Россия:   Фонд Сколково (медтех), РФФИ,
          программы Минздрава по цифровизации
Европа:   EU Horizon Health
США:      NIH (при наличии американского партнёра)
```

Детский научный проект как proof-of-concept —
сильная история для гранта.
"Школьники разработали прототип системы мониторинга пациентов"
— именно тот нарратив который работает.
